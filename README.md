# Metro Messenger 🚇💬

Легендарный реалтайм-мессенджер, созданный для общения двух друзей. 
Создан с целью послать нахуй ебанутые лимиты бесплатных хостингов (привет, InfinityFree) и получить нормальный, быстрый и красивый чат.

## 🚀 Фичи

*   **Реалтайм:** Мгновенная доставка сообщений благодаря WebSocket (Socket.io).
*   **Медиа:** Отправка картинок (через файл или вставку из буфера `Ctrl+V`) с полноценным лайтбоксом для просмотра.
*   **UX/UI:** 
    *   Ответы на сообщения (цитирование).
    *   Статус "Печатает...".
    *   Онлайн-статусы и время "был(а) в сети".
    *   Галочки прочтения (✓ / ✓✓).
    *   Звуковое оповещение о новом сообщении.
*   **Кастомизация:** 
    *   Смена аватарок (сохраняется на сервере).
    *   Установка кастомного фона для чата.
    *   Переключение между темной (Metro Dark) и светлой (Metro Light) темами.
*   **Админ-панель:** Кнопка полной очистки истории чата для обоих пользователей.

## 🛠 Технологии

*   **Backend:** Node.js, Express, Socket.io
*   **Frontend:** Vanilla JS, HTML5, CSS3 (без тяжелых фреймворков)
*   **Хостинг:** [Render](https://render.com) (Web Service)

## 👥 Аккаунты

Регистрация отключена, так как чат строго приватный. Доступны два захардкоженных аккаунта.

## 📦 Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/LitiyI0N/Metro-Messenger.git
2. Установите зависимости:
npm install
3. Запустите сервер:
npm install
4. Откройте http://localhost:3000 в браузере.

## ⚠️ Важно знать
Сервер хостится на бесплатном тарифе Render, поэтому если им не пользоваться 15 минут — он засыпает. Первое сообщение после пробуждения может идти до 50 секунд.

История сообщений хранится в оперативной памяти сервера. При перезапуске сервера (или его засыпании) — история очищается.

Сделано с любовью к Metro UI и ненавистью к хит-лимитам.
